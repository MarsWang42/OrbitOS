# 中国市场宏观数据源与报告节奏

## 用途

这张页回答 3 件事：

1. 宏观层去哪里找相对准确的数据
2. 宏观层一年应该做几次正式报告
3. 哪些变量更新后，能改哪一层判断
4. 具体监测项见 [[04_中国市场_宏观监测清单]]

## 先定顺序，再看数据

这条业务线的默认顺序是：

`宏观环境判断 -> 市场判断 -> 渠道判断 -> 产品线判断 -> 平台找款监控 -> 题材判断 -> 出图/上架验证`

这几个层级的职责要分清：

- 宏观环境判断：
  决定这个市场现在值不值得小步进入
- 市场判断：
  决定先做中国还是先做跨境，先重仓还是先试水
- 渠道判断：
  决定先盯哪些平台，平台各自承担什么角色
- 产品线判断：
  决定先做 `T恤`、卫衣，还是别的品类
- 平台找款监控：
  决定当前先跟哪些账号、店铺、关键词
- 题材判断：
  决定当前最值得先测的表达方向
- 出图 / 上架验证：
  决定设计和商品动作是否继续推进

## 回流规则

不是所有新信号都能直接改上游判断。

### 快变量

- 例：抖音热梗、小红书热点、挂车信号、评论区高频需求、平台规则小改
- 默认只能影响：
  - [[12_中国市场_T恤平台找款与监控闭环]]
  - [[13_中国市场_T恤首轮样本采集清单]]
  - [[14_中国市场_T恤样本采集记录表]]

### 中变量

- 例：季度消费数据、线上穿类增速、平台竞争强度变化、物流成本变化
- 可以影响：
  - [[11_中国市场_T恤产品线验证]]
  - [[02_中国市场_产品线总表]]
  - [[01_中国市场_渠道与策略]]

### 慢变量

- 例：人口结构、可支配收入、消费倾向、互联网渗透率、长期政策方向
- 才有资格影响：
  - [[00_中国市场_宏观环境与行业判断]]
  - [[中国市场POD业务验证]]

一句话规则：

`下游信号可以修正下游动作；只有被重复验证的中慢变量，才能往上改总判断。`

## 数据来源分层

## 双源对照规则

当前默认不是只信单一口径，而是按下面这条顺序取数：

`中国官方基线 -> 美国官方镜像指标 -> 平台一手数据 -> 第三方 / 国际中立源`

这 4 层各自承担的角色不同：

- 中国官方基线
  - 回答：中国市场的绝对量级到底是多少
  - 例：人口、收入、消费、网购规模、物流
- 美国官方镜像指标
  - 回答：如果换一个统计体系，这类消费、零售、电商、服饰指标通常怎么看
  - 更适合做方法校准和异常对照，不适合直接替代中国绝对数据
- 平台一手数据
  - 回答：现在抖音 / 小红书 / 商品端正在发生什么
- 第三方 / 国际中立源
  - 回答：当双边口径差距过大时，是否存在明显异常或样本偏差

一句话规则：

`中国数据定基线，美国数据做镜像，平台数据管动作，中立来源做仲裁。`

## 差异处理规则

如果中国官方口径和外部口径差异很大，不要直接选一边站队，先这样处理：

1. 先确认统计对象是否相同  
   例如是“穿类商品”“服装零售”“电商零售”“内容触发购物”，这些口径很容易不一样。
2. 再确认统计周期是否相同  
   月度、季度、年度混用时，差异会被放大。
3. 再确认统计范围是否相同  
   全国 / 城镇 / 网民 / 网购用户 / 某类平台用户，含义不同。
4. 如果仍差异明显  
   把该指标标成 `争议指标 / 低置信度指标`，暂时不让它单独推翻上层判断。

默认动作：

- 差异小：可直接纳入宏观判断
- 差异中等：只作为参考，不单独驱动决策
- 差异大：标红，等待第三来源补锚

### A层：官方基线数据

这层用来定“市场值不值得进”，优先级最高。

- 国家统计局
  - 用来查：社零总额、穿类商品零售、居民收入与消费支出、人口、就业、CPI
  - 入口：
    - [国家统计局](https://www.stats.gov.cn/)
    - [国家统计局数据发布库](https://www.stats.gov.cn/sj/zxfb/)
    - [2025年居民收入和消费支出情况](https://www.stats.gov.cn/zwfwck/sjfb/202601/t20260119_1962321.html)
- 中国政府网转官方数据
  - 用来快速看国家统计局和部委最新摘要
  - 入口：
    - [中国政府网数据频道](https://www.gov.cn/shuju/index.htm)
- CNNIC
  - 用来查：网民规模、网络购物用户规模、互联网渗透率
  - 入口：
    - [CNNIC 报告发布页](https://www.cnnic.cn/)
    - [第55次《中国互联网络发展状况统计报告》](https://www.cnnic.cn/n4/2025/0117/c88-11229.html)
- 国家邮政局
  - 用来查：快递业务量、电商物流活跃度、履约环境变化
  - 入口：
    - [国家邮政局](https://www.spb.gov.cn/)
    - [2025年上半年邮政行业运行情况](https://www.spb.gov.cn/gjyzj/c100015/c100016/202507/433736ca3a9043b5a8b5e8bef1d9c4ed.shtml)

### B层：行业与类目数据

这层用来定“服饰 / POD 这类业务当前在行业里处于什么位置”。

- 中国纺织工业联合会 / 中国服装协会
  - 用来查：服饰消费趋势、国潮 / 新中式 / 个性定制等行业信号
  - 入口：
    - [中国纺织工业联合会](https://www.cntac.org.cn/)
    - [服装消费趋势参考发布](https://www.cntac.org.cn/zixun/hangye/202505/t20250506_4382155.html)
- 网络视听 / 内容电商相关年度报告
  - 用来查：短视频、直播、电商内容消费路径
  - 当前可跟踪：
    - [中国网络视听节目服务协会相关发布](https://www.cnsa.cn/)
    - [第55次报告发布会说明页](https://www3.cnnic.cn/n4/2025/0123/c326-11244.html)

### C层：平台一手数据

这层用来定“现在平台上到底发生了什么”，比宏观层更快。

- 抖音 / 抖店体系
  - 用来查：热词、内容钩子、挂车与成交前信号、价格带
  - 优先入口：
    - 巨量算数
    - 抖店后台 / 罗盘
- 小红书体系
  - 用来查：题材反复出现、收藏信号、审美表达、人群语言
  - 优先入口：
    - 小红书站内搜索 / 话题 / 相关官方工具
- 淘宝 / 抖店商品端
  - 用来查：承接方式、价格带、评论区用户在意点

### D层：第三方信号工具

这层用来“加速发现”，不拿来单独定宏观结论。

- QuestMobile
- 飞瓜
- 蝉妈妈
- 千瓜

使用规则：

- 它们适合找信号，不适合单独当最终依据
- 第三方工具发现的机会，默认要回官方或平台一手数据补锚

### E层：美国官方镜像源

这层不是拿来替代中国数据，而是拿来做“统计口径镜像”和“异常值对照”。

- U.S. Census Bureau
  - 用来查：零售、电商零售、季度电商占比、零售节奏
  - 入口：
    - [Quarterly Retail E-Commerce Sales Report](https://www.census.gov/retail/ecommerce.html)
    - [Monthly Retail Trade release schedule](https://www.census.gov/retail/release_schedule.html)
- U.S. Bureau of Economic Analysis (BEA)
  - 用来查：个人收入、个人消费支出
  - 入口：
    - [Personal Income and Outlays](https://www.bea.gov/data/income-saving/personal-income)
- U.S. Bureau of Labor Statistics (BLS)
  - 用来查：CPI、服饰价格、消费价格变化
  - 入口：
    - [CPI Home](https://www.bls.gov/cpi/)

使用规则：

- 美国官方源适合回答“成熟统计体系下，这类指标通常怎么拆”
- 它不直接回答“中国市场绝对规模是多少”
- 但如果中国某项指标看起来异常乐观或异常保守，可以用美国官方镜像指标反查口径是否有问题

### F层：第三方 / 国际中立源

这层用于双边口径差异过大时做仲裁，不默认拿来当第一来源。

- World Bank
- OECD
- UN Data
- IMF

使用规则：

- 只在中国官方与美国官方镜像难以解释差异时启用
- 主要作用是判断“是统计口径不同，还是这个结论本身就不稳”

## 一年做几个报告

我建议分成 `1 + 4 + 12` 三层，不要全部都做成重报告。

### 1 份年度基线报告

- 名称建议：`中国市场POD年度宏观基线报告`
- 节奏：每年 `1` 次
- 时间建议：`1-2 月`
- 作用：
  - 重写 [[00_中国市场_宏观环境与行业判断]]
  - 决定这一年还要不要继续做中国线
  - 决定今年优先哪些产品线
  - 优先使用上年全年统计、公报和年度行业报告

### 4 份季度更新简报

- 名称建议：`中国市场POD宏观季度更新`
- 节奏：每季度 `1` 次
- 作用：
  - 更新消费、零售、服饰、物流、平台生态变化
  - 判断是否需要调整 [[01_中国市场_渠道与策略]] 和 [[02_中国市场_产品线总表]]
  - 优先使用季度消费、收入、快递和平台生态变化

### 12 份月度信号简报

- 名称建议：`中国市场POD平台与消费月报`
- 节奏：每月 `1` 次
- 作用：
  - 看平台热点、节日节点、评论区需求变化、价格带变化
  - 主要服务 [[11_中国市场_T恤产品线验证]] 和 [[12_中国市场_T恤平台找款与监控闭环]]
  - 不直接推翻宏观层，只负责把快变量送给动作层

### 周度信号记录

- 不算正式宏观报告
- 只在当前产品线活跃执行时才做
- 作用：
  - 防止你每周都去翻所有旧日记
  - 但它不能单独推翻宏观层判断

## 建议跟踪的核心变量

### 慢变量

- 人口结构
- 年龄层变化
- 城乡消费结构
- 居民可支配收入
- 消费倾向
- 互联网与网络购物渗透率
- 长期政策与合规方向

### 中变量

- 穿类商品线上增速
- 内容电商成交环境
- 平台流量竞争强度
- 物流与履约环境
- 行业竞争与同质化程度

### 快变量

- 季节与节日
- 平台热词
- 小红书热门表达
- 抖音挂车与评论区需求
- 店铺价格带变化
- 题材生命周期

## 当前执行规则

- 先把这张页定为中国线的宏观调研操作页
- 以后所有宏观结论先回写 [[00_中国市场_宏观环境与行业判断]]
- 所有月度 / 季度变化，先判断属于快变量、中变量还是慢变量，再决定更新哪一层
- 具体盯哪些指标，默认按 [[04_中国市场_宏观监测清单]] 执行
