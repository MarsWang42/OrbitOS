# 中国市场宏观监测清单

## 用途

这张页回答的是：

- 宏观层面到底要长期盯什么
- 哪些指标是真正会影响 `POD` 业务判断的
- 这些指标应该按什么频率更新

## 监测总原则

- 不是宏观上什么都盯，而是只盯会影响“需求 / 供给 / 流量 / 转化 / 履约 / 风险”的变量
- 宏观监测的目的不是做学术研究，而是服务业务判断
- 邮政和快递总量只能算表层容量指标，不能替代退货率、尺码稳定性、印花质量这类底层痛点指标
- 每个指标都要带上：
  - 它影响哪一层
  - 更新频率
  - 默认数据来源

## A. 需求侧

### 1. 居民收入与消费倾向

- 监测什么：
  - 居民可支配收入
  - 居民消费支出
  - 消费倾向变化
- 为什么要盯：
  - 决定用户是不是更愿意买“情绪价值型”商品
- 更新频率：
  - 季度 / 年度
- 默认来源：
  - 国家统计局

### 2. 社会消费品零售与穿类消费

- 监测什么：
  - 社零总额增速
  - 穿类商品零售增速
  - 网上穿类商品增速
- 为什么要盯：
  - 决定服饰是不是在放量，还是已经明显承压
- 更新频率：
  - 月度 / 季度
- 默认来源：
  - 国家统计局
  - 中国政府网转官方数据

## B. 人口与社会结构

### 3. 年龄结构与家庭结构

- 监测什么：
  - 年龄层变化
  - 婚育与家庭结构
  - 城乡结构
- 为什么要盯：
  - 决定什么表达更容易成立，比如自我表达、关系表达、送礼表达
- 更新频率：
  - 年度
- 默认来源：
  - 国家统计局人口统计公报

### 4. 社会情绪与生活方式

- 监测什么：
  - 情绪型消费
  - 身份表达
  - 城市 / 方言 / 圈层表达
- 为什么要盯：
  - 决定 `POD` 更应该卖“基础款”还是“表达”
- 更新频率：
  - 月度观察 + 季度总结
- 默认来源：
  - 小红书 / 抖音平台样本
  - 行业观察报告

## C. 互联网与内容平台

### 5. 网民、网购与短视频渗透率

- 监测什么：
  - 网民规模
  - 网络购物用户规模
  - 短视频 / 直播渗透率
- 为什么要盯：
  - 决定“内容触发成交”这条路是不是仍然成立
- 更新频率：
  - 半年 / 年度
- 默认来源：
  - CNNIC
  - 网络视听相关年度报告

### 6. 平台生态变化

- 监测什么：
  - 抖音内容生态
  - 小红书审美表达
  - 商品承接路径
  - 平台规则变化
- 为什么要盯：
  - 决定你该把精力放在哪个平台、哪种表达方式
- 更新频率：
  - 月度
- 默认来源：
  - 平台一手观察
  - 平台后台 / 官方工具

## D. 行业与类目

### 7. 服饰行业与个性化表达趋势

- 监测什么：
  - 个性化、定制化、国潮、新中式等趋势
  - 服饰行业竞争度
  - 表达型服饰机会
- 为什么要盯：
  - 决定 `POD` 是不是有题材空间，而不只是低价内卷
- 更新频率：
  - 季度 / 年度
- 默认来源：
  - 中国纺织工业联合会
  - 服饰行业协会与专题报告

### 8. 同类业务竞争与品牌打法

- 监测什么：
  - 表达型服饰品牌
  - 平台上卖得动的内容打法
  - 同质化程度
- 为什么要盯：
  - 决定当前应该做“题材差异化”还是“执行效率差异化”
- 更新频率：
  - 月度 / 季度
- 默认来源：
  - 平台样本
  - 第三方信号工具

## E. 供给与履约

### 9. 物流与履约环境

- 监测什么：
  - 快递业务量
  - 履约效率
  - 重要节前物流波动
- 为什么要盯：
  - 决定什么节点适合推，什么节点履约风险高
- 更新频率：
  - 月度 / 节点前
- 默认来源：
  - 国家邮政局
- 当前边界：
  - 这项只能证明“物流环境总体可用”
  - 不能单独证明 `POD` 生意本身健康

### 10. 供应链与成本

- 监测什么：
  - 面料、印花、打样、退货风险
  - 基础成本与价格带
- 为什么要盯：
  - 决定 `POD` 测试是不是还能保住毛利
- 更新频率：
  - 月度 / 季度
- 默认来源：
  - 供应链沟通
  - 店铺样本
  - 平台价格带观察

### 10.1 底层痛点指标

- 监测什么：
  - 退货率 / 退款率
  - 退货原因结构
  - 尺码稳定性
  - 印花质感与洗后表现
  - 客服争议点
  - 差评集中原因
- 为什么要盯：
  - 这些指标比表层规模更直接决定 `POD` 能不能活
- 更新频率：
  - 月度 / 每轮验证后
- 默认来源：
  - 店铺评论
  - 售后记录
  - 样本复盘
  - 小规模实测

## F. 节点与周期

### 11. 季节性

- 监测什么：
  - 春夏秋冬上新节奏
  - 短袖 / 卫衣的季节窗口
- 为什么要盯：
  - 决定什么时候测 `T恤`，什么时候切卫衣
- 更新频率：
  - 月度

### 12. 节日与营销节点

- 监测什么：
  - 618
  - 双 11
  - 开学季
  - 情人节 / 母亲节 / 父亲节 / 春节等送礼节点
- 为什么要盯：
  - 决定送礼表达、关系表达类题材什么时候更容易起量
- 更新频率：
  - 节点前 `2-4` 周重点跟踪

## G. 风险与规则

### 13. 政策、平台规则与版权风险

- 监测什么：
  - 平台规则收紧
  - 内容审核变化
  - 图案 / 文字版权风险
- 为什么要盯：
  - 决定哪些题材能做，哪些表达虽然火但不能碰
- 更新频率：
  - 月度 + 发生变化时即时更新
- 默认来源：
  - 平台规则页
  - 法规 / 官方公告

## 最终只看这 8 组核心变量

如果只保留最核心的，优先盯这 8 组：

1. 居民收入与消费倾向
2. 穿类商品线上增速
3. 年龄 / 家庭 / 城乡结构
4. 网购与短视频渗透率
5. 抖音 / 小红书平台生态变化
6. 服饰表达趋势与行业同质化
7. 物流与履约环境
8. 季节 / 节日 / 平台规则
