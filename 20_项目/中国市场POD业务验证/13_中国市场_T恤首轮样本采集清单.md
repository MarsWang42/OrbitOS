# 中国市场 T恤首轮样本采集清单

## 这页负责什么

这页负责把“去哪里找、找什么、什么值得记”固定下来，确保样本采集不是随手收藏，而是为题材判断服务。

## 当前锁定方向

- 当前先不锁死单一风格
- 当前先以抖音 / 小红书上的真实找款信号为准
- 产品：T 恤为主
- 目标：先找“反复出现、互动不差、表达明确、容易做内容”的题材方向

## 采集目标

不是“看到好看就存”，而是为了回答三个问题：

1. 哪类题材在抖音 / 小红书上连续出现
2. 哪类内容表达最容易触发互动或购买意图
3. 哪个方向最值得先做第一轮 T 恤 POD 测试

## 建议样本量

- 抖音：8-10 条
- 小红书：8-10 条
- 淘宝 / 抖店商品页：4-6 条
- 品牌或店铺参考：2-4 个

合计先做 `22-30` 条就够，先求能收束，不求一开始铺太大。

## 每条样本都记录这 10 项

- 链接或截图来源
- 平台
- 发布时间或观察时间
- 题材标签
- 视觉 / 文案关键词
- 内容钩子或标题写法
- 互动信号（赞 / 评 / 藏 / 转）
- 是否挂车 / 商品承接
- 价格带或店铺信号
- 是否符合当前候选池

## 样本分类方式

### 内容样本

- 视频钩子是什么
- 停留点是什么
- 是靠穿搭感、情绪感、文案感还是图案感在吸引人
- 评论区有没有“想买 / 哪里买 / 适合送人 / 这就是我”的反馈

### 商品样本

- 主图风格
- 价格带
- 图案位置
- 款式版型
- 评论区用户在意什么
- 是否和内容端表达一致

### 品牌样本

- 品牌是否有统一风格
- 是否系列化
- 文案口吻是什么
- 是否能看出稳定上新节奏

## 优先采集的关键词方向

- 打工人 T 恤
- 情绪文字 T 恤
- 精神状态短袖
- 新中式文字 T 恤
- 国潮文案 T 恤
- 城市方言 T 恤
- 宠物关系表达 T 恤
- 送礼梗 / 朋友梗 T 恤

## 采集完成后的输出

- 一份“平台反馈最强的题材方向总结”
- 一份“最值得先做的 1-3 个方向”
- 一份“暂时不要做的方向”
- 一组“下轮继续监控的关键词”

## 与出图链路的衔接

样本采集完成后，再进入出图阶段：

1. 先从平台反馈最强的 `1` 个题材开始
2. 再做首轮图案与主图风格探索
3. 再做批量变体
4. 保留每轮图的命名规则和版本记录
