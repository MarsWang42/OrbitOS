# 底层痛点指标库

## 用途

这张页专门盯那些“看起来不宏观，但实际上最决定 `POD` 能不能活”的指标。

## 当前定位

这张页是整个项目里最靠近业务生死线的一层。

宏观页回答“盘子在不在”，这张页回答“做进去以后会不会被现实吃掉”。

## 为什么它比邮政量更重要

- 邮政 / 快递总量只能说明社会物流系统还在转
- 它不能说明你的 `POD` 订单是不是在大量退货
- 也不能说明用户为什么退款、为什么差评、为什么不复购

所以：

`邮政量 = 表层容量指标`

`退货、尺码、印花、客服、履约争议 = 底层痛点指标`

## 当前最该长期盯的痛点

### 1. 退货率 / 退款率

- 为什么关键：
  - 这是最直接吞利润的指标
- 重点看：
  - 不同产品线退货率
  - 不同题材退货率
  - 内容爆了但退货高不高

### 2. 退货原因结构

- 重点看：
  - 尺码不合适
  - 面料 / 厚薄不符
  - 印花质感不符
  - 色差
  - 版型问题
  - 与预期不符

### 3. 尺码稳定性

- 重点看：
  - 同版型不同批次偏差
  - 女款 / 中性款反馈差异
  - 评论区高频尺码问题

### 4. 印花与洗后稳定性

- 重点看：
  - 掉色
  - 开裂
  - 发硬
  - 洗后图案变化

### 5. 履约时效与异常波动

- 重点看：
  - 节前延迟
  - 爆单时延迟
  - 偏远地区异常

### 6. 客服摩擦成本

- 重点看：
  - 高频咨询问题
  - 售前拦截点
  - 售后争议点

### 7. 差评与中评集中点

- 重点看：
  - 是否都集中在某几个问题
  - 是否说明不是单次失误，而是结构性问题

### 8. 复购与推荐意愿

- 重点看：
  - 用户是否只买一次
  - 是否愿意送人 / 推荐
  - 是否会期待同系列上新

## 影响分层

- 只看邮政量：最多改“履约环境总体可用”
- 看到退货率和差评结构：可以直接改产品线和题材判断
- 看到长期高退货 + 高售后摩擦：可以直接推翻“这条产品线值得先做”

## 当前规则

- 以后宏观层不再把邮政量当作强结论来源
- 邮政数据只保留为“物流环境总体可用”的辅助证据
- 真正影响业务生死的，优先看这张页里的底层指标
