# 双源对照与数据源治理

## 默认规则

宏观层默认不单信单一来源。

顺序是：

`中国官方基线 -> 美国官方镜像 -> 平台一手数据 -> 中立来源补锚`

## 当前定位

这张页处理的是“同一个判断到底该信谁”的问题，不是单纯罗列数据源。

它的作用有两个：

- 给中国线提供绝对量级基线
- 给跨境线提供镜像对照和口径校准

## 为什么要这样

- 中国官方数据更适合定中国市场绝对量级
- 美国官方数据更适合做成熟统计体系下的镜像对照
- 平台一手数据更接近当前业务动作
- 中立来源更适合在差异过大时做仲裁

## 差异处理

如果两个来源差异大，不立刻下结论，先查：

1. 统计对象是否一致
2. 统计周期是否一致
3. 统计范围是否一致
4. 统计口径是否一致

如果仍然差异明显：

- 标成 `争议指标`
- 不让它单独推翻上层判断

## 输出物

这张页最终要给出去的，不是源列表，而是三类结果：

- 基线结论：当前先信哪一层
- 争议指标：哪些指标先标低置信度
- 回流动作：哪些分歧需要回到 `03`、`04` 或 `05` 继续看
