# 双线共通判断与回流机制

## 用途

这张页负责把中国线和跨境线共用的判断口径、回流顺序和完成标准收束起来。

## 当前判断

- 两条线不需要两套完全不同的宏观逻辑
- 共通部分是：容量判断、数据源治理、报告节奏、底层痛点指标
- 差异部分是：平台语境、内容入口、商品承接、价格带与履约体验

## 共通顺序

两条线都先走同一条判断链：

`宏观容量 -> 数据源治理 -> 报告节奏 -> 底层痛点指标 -> 线别观察页 -> 产品线验证 -> 平台样本回流`

## 完成定义

当下面几件事同时成立时，这个项目就算进入可交付状态：

- `01-05` 的核心页已经形成同构结构，且互链清楚
- 中国线可以按这套框架持续复盘
- 跨境线可以按同一逻辑镜像复制
- 样本、报告、指标能够稳定回流到项目页，而不是散落在执行页
- 本页能够把双线的回流顺序写清楚

## 回流顺序

- 样本记录先回到对应产品线验证页
- 产品线验证再回到项目支撑页
- 支撑页再回到总项目页
- 只有重复出现的中慢变量，才有资格往上改宏观判断

## 当前下一步

1. 先把主项目页和 `01-05` 的互链补齐，保证双线都能从同一个入口进来
2. 中国线先用 `T恤` 跑第一轮底层痛点观察
3. 跨境线先保持镜像结构，等中国线方法稳定后再复制
