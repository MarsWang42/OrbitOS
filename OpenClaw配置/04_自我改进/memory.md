# 记忆蒸馏工作台

这页用于承接 `memory-distillation` 的热记忆整理工作。

定位：

- 这里放“刚蒸馏出来、但还没完全沉到最终位置”的记忆
- 它是过渡工作台，不是最终知识库
- 稳定后应继续归位到主控记忆、用户偏好或知识摘录

## 一、进入条件

以下内容适合先进入这页：

- 一轮项目或系统整理刚结束
- 平台接入、排错、迁移后刚形成结论
- 同类偏好或规则已重复出现两次以上
- 需要先压缩会话经验，再决定最终归位

## 二、蒸馏原则

- 只留长期稳定内容
- 一条记忆只表达一件事
- 先结论，后少量上下文
- 不记录敏感信息
- 不保留过期链接、授权码、二维码

## 三、归位规则

- 用户长期偏好：
  归位到 [[OpenClaw配置/01_主控/USER|USER]]
- 主控长期规则：
  归位到 [[OpenClaw配置/01_主控/MEMORY|MEMORY]]
- 角色方法和经验：
  归位到 [[OpenClaw配置/03_知识摘录/README|知识摘录]]
- 系统级总结：
  归位到 `99_系统`
