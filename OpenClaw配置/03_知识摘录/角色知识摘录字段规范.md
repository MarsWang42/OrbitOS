# 角色知识摘录字段规范

这页用于统一 `OpenClaw配置/03_知识摘录` 下各角色经验笔记的最小字段。

## 推荐 frontmatter

```yaml
type: role_excerpt
created: YYYY-MM-DD
role:
topic:
confidence:
thinking_mode:
claim_type:
evidence_level:
validation_status:
source_task:
source_note:
tags: []
```

## 样本积累类摘录建议补充字段

如果这条摘录来自用户持续投喂的链接、图片、视频、案例或样本，建议额外补：

```yaml
sample_type:
preference_signal:
fit_for_user:
anti_pattern:
sample_source:
```

## 字段说明

- `role`
  - 角色名，如 `moushi / diaoyan / jishu`
- `topic`
  - 这条经验围绕的主题
- `confidence`
  - 当前经验置信度
- `thinking_mode`
  - 这条经验主要依赖的思维模式
- `claim_type`
  - 当前更接近原则、事实、规律、假设还是想法
- `evidence_level`
  - 依据强度，推荐 `A / B / C / D`
- `validation_status`
  - 当前是否未验证、部分验证、已验证或已复用
- `source_task`
  - 来自哪类任务
- `source_note`
  - 来自哪条研究/项目/会话沉淀
- `sample_type`
  - 样本类型，如 `链接 / 图片 / 视频 / 页面 / 文案 / 项目案例`
- `preference_signal`
  - 这条样本体现出的偏好信号
- `fit_for_user`
  - 当前更适合用户、部分适合，还是不适合
- `anti_pattern`
  - 这条样本反向暴露出的不喜欢或不适用模式
- `sample_source`
  - 原始样本来源，如某个平台、链接或素材池

## 和主知识区的区别

- 这里存“这个角色学到了什么”
- 这里也存“这个角色通过样本逐渐看懂了你什么”
- `30_研究 / 40_知识库` 存“你最终保留什么”

不要把角色摘录直接当最终知识库用。
