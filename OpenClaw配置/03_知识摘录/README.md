这里存放 OpenClaw 各角色从会话和执行结果里沉淀出来的知识摘录。

这一层也承担一个重要作用：

- 让专家角色通过持续样本积累，慢慢形成更贴近用户的判断体系

例如：

- `sheji` 不只是看素材，而是逐步形成你的审美偏好与反偏好
- `diaoyan` 不只是收来源，而是逐步形成你的来源判断口径
- `yewen` 不只是写文案，而是逐步形成你的表达节奏与语言边界

## 说明

- 来源是 OpenClaw 工作区与运行会话
- 内容本质上属于“角色经验层”，不是用户主知识库
- 内容偏自动化整理，不等于人工精修知识
- 适合作为后续整理到 `30_研究` 或 `40_知识库` 的中间层
- 不建议把这一层直接当作最终知识库使用

## 这层和其他内容的边界

- 它不是 `Skill`
- 它不是 `SOP`
- 它也不是用户最终知识卡片

它更适合回答：

- 某个角色在多次执行后，学到了什么
- 哪些判断和经验值得继续积累
- 哪些内容值得再提炼进用户主知识区

## 建议用法

- 先在这里聚合
- 再定期人工筛选
- 有价值的内容再沉淀进 OrbitOS 主知识区

推荐链路：

`用户给样本 -> 角色比较与标注 -> 角色摘录 -> 多次验证 -> 研究 / 知识沉淀`

要注意：

- 样本积累不等于原始素材囤积
- 更重要的是提炼“偏好信号、反偏好信号、适配条件和边界”
