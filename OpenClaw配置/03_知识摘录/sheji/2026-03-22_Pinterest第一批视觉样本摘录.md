# Pinterest第一批视觉样本摘录

## 场景

- 这条经验来自你提供的 3 个 Pinterest pin，以及当前 `视觉 / 西部牛仔风格 / 美式复古` 板块截图
- 目标不是做一次性“好不好看”判断，而是提炼第一批可复用审美信号

## 摘录结论

- 你的视觉偏好目前不是单一风格，而是一个多层混合系统：
  - 基底层偏 `美式复古 / 工装 / 常春藤 / 西部牛仔`
  - 画面层偏 `暖木色空间 / 旧感室内 / 低饱和穿搭摄影`
  - 图形层又允许 `复古印花 / airbrush / chrome / 老式字效`
- 这说明你的审美不是“只喜欢一种图”，而是同时在积两类东西：
  - `穿搭与品牌氛围`
  - `图案与图形语言`

## 判断依据

- 从当前截图可见，视觉板里反复出现这些信号：
  - 木色、棕绿、米白、酒红、深蓝等偏旧感配色
  - 室内复古陈设、暖木背景、人物造型摄影
  - 宽松轮廓、工装 / 学院 / 复古混搭
- 在 `美式复古` 板块里，又能看到另一组高频信号：
  - 骷髅、鹰、火焰、闪电、天使、老式印花
  - 复古字标、airbrush、金属感字效、老 T 图案语言
- 这两组看似分离，但底层共性是：
  - 都偏“旧感、带故事、带年代感”
  - 都排斥太新、太平、太无质感的视觉

## 当前提炼出的偏好信号

- 喜欢：
  - 有旧感与时间感的视觉
  - 暖木色、低饱和、复古空间氛围
  - 宽松轮廓、工装/学院/牛仔的混合感
  - 有图形语言和性格的复古印花
- 不喜欢：
  - 纯白净、过度扁平、没有质感的视觉
  - 太甜、太软、太少女向的表达
  - 只有风格标签、没有具体材质和年代感支撑的“伪复古”

## 结论类型与验证

- 当前更接近：`规律 / 偏好信号`
- 依据强度：`C`
- 当前验证状态：
  - 已有反复收藏信号
  - 但还未经过真实项目验证
  - 暂时只能算“阶段性稳定偏好”，还不是最终设计原则

## 适用边界

- 适合什么情况：
  - 做品牌氛围参考
  - 做穿搭风格、图案方向、视觉 moodboard
  - 为后续 `sheji` 的视觉 brief 提供审美底稿
- 不适合什么情况：
  - 直接把收藏频率当最终结论
  - 不区分“穿搭喜欢”和“图案可做”
  - 不经项目验证就把某种视觉升级为稳定品牌方向

## 后续流向

- 是否值得整理进 `30_研究`：值得，适合后续做“你的视觉系统研究”
- 是否值得提炼进 `40_知识库`：部分值得，需再经项目验证
- 是否只保留在角色经验层：当前先保留这里更稳

## 下一步建议

- 从这 3 个 pin 再各补 2 个相似样本，验证是不是仍然收敛到同一批信号
- 把视觉样本分成两簇：
  - `穿搭 / 品牌氛围簇`
  - `图案 / 图形语言簇`
- 后续在真实项目里测试：
  - 哪些更适合品牌氛围
  - 哪些更适合图案落地
