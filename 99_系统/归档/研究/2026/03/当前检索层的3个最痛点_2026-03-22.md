# 当前检索层的3个最痛点

## 一句话结论

你现在最缺的不是“再多一个搜索工具”，而是把现有检索动作统一成一条可解释、可分层、可持续扩展的默认工作流。当前最明显的 3 个痛点是：**入口不统一、命中原因不透明、跨层读取不成体系**。

## 痛点 1：入口不统一

### 现象

同样是“找内容”，你现在会混着用很多入口：

- `搜索定锚`
- `推荐扩展`
- `平台专用链路`
- `通用抓取`
- `主来源补锚`
- `memory-lancedb`
- Obsidian 内部已有笔记

这些入口各自都成立，但它们还没有被压成稳定的默认顺序。

### 结果

- 遇到新问题时，还是容易靠临场判断
- 同样类型的链接，处理方式可能每次不一样
- 很难形成可复用的“先做什么、后做什么”的检索动作

### 当前证据

- [[99_系统/归档/研究/2026/03/视频内容获取方法与学习深度升级_2026-03-22]]
- [[99_系统/链接学习筛选与去重规则]]

### 本质

不是没有工具，而是：

`入口太多，但默认顺序还不够硬。`

## 痛点 2：命中原因不透明

### 现象

你现在已经能做到：

- 找到一手来源
- 补锚
- 回链
- 沉淀到研究 / 知识 / 项目

但还不够清楚：

- 这次为什么命中了这条内容
- 为什么没命中另一条
- 当前到底是搜索命中的，还是推荐带出来的
- 是平台专用链路有效，还是通用链路补到的

### 结果

- 排障时容易重复摸索
- 复盘时不容易直接回答“到底哪一步最值”
- 后续做自动化时，很难把检索过程产品化

### 当前证据

- 你现在已经在手工留痕，但更多是“结果留痕”
- 还没有一套稳定的“检索轨迹留痕”

### 本质

不是完全不可追溯，而是：

`结果能追溯，检索路径还不够可观测。`

## 痛点 3：跨层读取不成体系

### 现象

你当前的内容分布已经很多层：

- `00_收件箱`
- `30_研究`
- `40_知识库`
- `50_资源`
- `角色知识摘录`
- `memory-lancedb`
- `Skills / SOP / 模板`

这些层都合理，但 Agent 在“运行时到底先读哪层、怎么跨层找、什么时候该停”这件事上，还没有统一的上下文读取体系。

### 结果

- 你自己知道结构，但 Agent 读取逻辑还偏手工规则
- 层与层之间的边界明确了，读取顺序却还不够强
- 系统一复杂，就容易开始觉得“脑子过载”

### 当前证据

- [[99_系统/OpenClaw记忆层使用与治理规则]]
- [[99_系统/归档/研究/2026/03/当前系统_vs_OpenViking_对照表_2026-03-22]]

### 本质

不是分层错了，而是：

`分层已经有了，但跨层检索和加载还没完全系统化。`

## 这 3 个痛点和 OpenViking 的对应关系

| 当前痛点 | OpenViking 对应强项 | 当前判断 |
|---|---|---|
| 入口不统一 | 文件系统式统一上下文 + 分层加载 | 有帮助 |
| 命中原因不透明 | 检索轨迹可观测 | 非常有帮助 |
| 跨层读取不成体系 | 统一管理 `记忆 / 资源 / 技能` | 有帮助 |

所以 `OpenViking` 最值得试的，不是“存更多内容”，而是：

`让检索入口、检索路径和跨层加载更清楚。`

## 当前最该先补哪一个

如果只按优先级排：

1. **命中原因不透明**
2. **入口不统一**
3. **跨层读取不成体系**

原因是：

- 第二和第三个问题，很多时候还能靠你自己手工兜住
- 但第一点如果不解决，后面很难真正把检索层做成稳定系统

## 当前最推荐的下一步

现在最值的动作不是装新系统，而是先做一张：

`当前检索路径图`

至少把下面这几种入口画清楚：

- 搜索定锚
- 推荐扩展
- 平台专用链路
- 通用抓取
- 主来源补锚
- Obsidian 内部正式笔记
- 记忆层辅助召回

这一步已经完成第一版：

- [[99_系统/归档/研究/2026/03/当前检索路径图_2026-03-22]]

下一步最值的是：

- 用 [[99_系统/模板/检索轨迹记录模板]] 连续记录 3 条真实样本
- 再用 [[99_系统/归档/研究/2026/03/OpenViking检索层最小试点方案_2026-03-22]] 判断是否值得进入真正试点

然后再标：

- 哪一步最常用
- 哪一步最不稳定
- 哪一步最不透明

## 当前结论

- 你现在最真实的检索问题，不是“缺工具”
- 而是“缺一套更统一、更透明的检索运行层”
- 这也正好解释了为什么 `OpenViking` 最适合先从检索层试点
