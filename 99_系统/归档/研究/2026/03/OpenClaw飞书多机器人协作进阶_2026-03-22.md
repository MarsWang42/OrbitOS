# OpenClaw飞书多机器人协作进阶玩法

> 来源：B站教程视频
> 链接：https://b23.tv/lGyibGo
> UP主：同频道

## 内容摘要

讲解如何为每个 Agent 助手配置独立飞书机器人，实现进阶协作体验。

### 核心内容

1. **为什么需要多机器人**
   - 群聊管理方案是「入门方案」，能跑但不够爽
   - 门槛高，使用久了发现局限性

2. **进阶版：每个Agent配独立飞书机器人**

   | 功能 | 说明 |
   |------|------|
   | 独立名字+头像 | 不再串台 |
   | 私聊流式输出 | 不用干等 |
   | 快捷指令 | 常用操作一键搞定 |
   | 多机器人协作 | 一个群能拉多个机器人协作干活 |

3. **配置方式**
   - 做成 Skill，跟着提示填就行
   - 自动备份、自动绑定、自动重启
   - 全程不用碰配置文件

4. **兼容性**
   - 群聊方案依然能用
   - 进阶玩法让体验再上一个台阶
