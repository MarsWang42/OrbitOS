## 补锚结果

### 1. promptfoo

- 一手来源：[promptfoo/promptfoo](https://github.com/promptfoo/promptfoo)
- 当前判断：用于测试 prompts、agents 和 RAG 的评估与红队工具，偏安全测试与评测基础设施。
- 与当前系统关系：更适合后续做 `验证 / 审核 / 评测` 能力补强。

### 2. agency-agents

- 一手来源：[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
- 当前判断：一套多角色 AI 代理集合，强调分工、人格、流程与交付物。
- 与当前系统关系：和你现在的“谋士 -> 专家角色 -> 审核”分工思路高度相关，适合做角色设计对标。

### 3. awesome-openclaw-skills

- 一手来源：[sundial-org/awesome-openclaw-skills](https://github.com/sundial-org/awesome-openclaw-skills)
- 当前判断：OpenClaw 技能的精选聚合清单，偏技能发现与能力扩容。
- 与当前系统关系：和“候选来源池 / 能力池扩容”直接相关，适合后续补能力入口。

### 4. claude-hud

- 一手来源：[jarrodwatts/claude-hud](https://github.com/jarrodwatts/claude-hud)
- 当前判断：Claude Code 的状态 HUD 插件，可显示上下文使用、工具活动、agent 状态和 todo 进度。
- 与当前系统关系：更偏可观测性和过程可视化，适合后续优化“运行过程可见性”。

### 5. OpenViking

- 一手来源：[volcengine/OpenViking](https://github.com/volcengine/OpenViking)
- 当前判断：面向 AI Agents 的上下文数据库，用文件系统式范式统一记忆、资源和技能管理。
- 与当前系统关系：和你现在的“记忆层 / 知识层 / 资源层”结构高度相关，属于非常值得继续深挖的候选。
- 已继续深挖：[[99_系统/归档/研究/2026/03/OpenViking_2026-03-22]]
