# 当前已接入平台清单

这篇用于记录当前 Obsidian + OpenClaw + Agent Reach 的平台接入状态。

相关入口：

- [[99_系统导航索引]]
- [[OpenClaw配置/00_后台与文档/README|OpenClaw 配置入口]]
- [[OpenClaw配置/06_Skills/README|Skills 入口]]

## 一、已验证可用

以下平台已经完成真实可用验证，不只是装上工具：

- GitHub
  已完成 `gh auth login`
  可读取、搜索仓库，支持 Issue、PR、Fork 等操作
- 任意网页
  通过 `Jina Reader` 可读网页正文
- Exa 全网语义搜索
  已通过 `mcporter` 接通
- Twitter / X
  `xreach` 已装好并可用
- 微博
  `mcp-server-weibo` 已接通并完成 MCP 工具验证
- B站
  `yt-dlp` 已完成真实视频读取验证
  匿名链路已能稳定拿到标题、UP 主、时长与章节结构
  正常字幕当前不能视为默认可得；部分样本即便补 `cookies-from-browser` 也未必返回
- RSS
  可读取 RSS / Atom 源
- 微信公众号
  已完成 Agent Reach 接入
- 小红书
  已完成登录
  已完成 `search_feeds(keyword: "AI")` 实测
- 抖音
  已完成部分公开视频解析与无水印链接获取验证
  但部分分享链仍要求 `fresh cookies`，当前不能视为稳定无登录抓取

## 二、已接通待进一步配置

- 小宇宙播客
  通道在 Agent Reach 中已支持
  还需要配置 `Groq API Key`
- LinkedIn
  还未安装和接入对应 MCP

## 三、可部分使用但受环境影响

- Reddit
  当前无代理，公开 JSON 接口不稳定
- V2EX
  当前有本机 SSL 证书问题
- B站搜索
  视频读取已可用
  搜索仍可能受 B站接口或反爬影响
- YouTube
  搜索层已可用
  正式 `watch` 链接的深取仍受 anti-bot 影响
  browser 方案当前能确认字幕轨道存在，但正文仍可能为空
  当前不能把字幕视为稳定默认可得

## 五、当前结论

当前最核心的平台能力已经形成可用组合：

- 搜索：Exa、Twitter/X、微博、小红书
- 内容读取：网页、GitHub、B站、微信公众号、RSS
- 视频类：B站、YouTube（搜索 / 元信息层）、抖音
- 当前更准确的默认动作：
  - B站先用 `yt-dlp` 匿名拿结构化信息，再视需要补字幕 / cookies
  - YouTube 先试 `yt-dlp` 元信息；受阻时先看 browser 轨道确认，仍无正文就转人工片段验证
- 中文社媒：微博、小红书、抖音、微信公众号

如果后续继续扩展，优先级建议是：

1. LinkedIn
2. 小宇宙
3. Reddit 代理
4. V2EX 证书修复
